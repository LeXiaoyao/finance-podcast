外资重磅第9期｜反内卷能不能从政策语言变成利润语言？

发布时间：2026-05-25 21:40:07 +0800

节目简介

反内卷被外资视为继出海、人工智能之后的第三大盈利驱动——前两个是开源，反内卷讲的是存量市场的利润再分配，而且是结构性的节流。在外资的中国资产估值模型里，价格战是利润表上最难修复的损耗；如果某些行业能从杀价模式切换到价格修复模式，过去几年被砍掉的中国制造业溢价，就有理由重新加回去。

本期围绕四条主线展开：新能源车（头部集中度提升 + 政策端规范市场秩序）、光伏（产能出清节奏决定价格修复弹性）、电商与外卖（平台从规模优先回到利润优先）、传统制造业（钢铁、水泥、玻璃的价格秩序）。同时讨论外资仍在反复争论的三个问题：政策驱动 vs 市场驱动、是否会引发温和通胀、受益板块如何排序。

外资的态度目前可以概括为"相信方向，等待证据"。下半年要看的，是反内卷从政策语言变成利润语言的第一份财报证据——重点关注光伏产能出清进度、头部车企毛利率环比、以及电商平台年中策略会的口径变化。三条反转条件也值得跟踪：需求继续走弱倒逼重打价格战、政策反复、出口受阻使产能压力重回国内。
