外资重磅第80期｜金饰少买三成，金条多买三成：同样是黄金，钱为什么换了去处？

发布时间：2026-10-07 23:54:26 +0800

节目简介

2026年上半年，中国金饰需求按重量下降30%，金条与金币需求却增长31%。同样是黄金，消费者、投资者和黄金企业为何作出不同选择？

本期从婚庆预算与黄金投资的差别出发，结合瑞银对长期储备需求与短期利率压力的分析，解释央行增持为何不等于金价托底。再看周大福销售金额与件数的分化、关店后的同店口径，以及紫金矿业的多金属业务、产量和成本。

二季度金条与金币需求同比回落，仍高于过去十年的同季平均水平。看黄金的热度，需要同时分清购买目的、时间参照和企业经营，不能把行业吨数直接换算成公司利润。
