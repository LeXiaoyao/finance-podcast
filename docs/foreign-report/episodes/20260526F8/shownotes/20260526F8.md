# 外资重磅第8期｜Pfizer 为什么愿意付 12.5 亿美元买中国药？

## 本期简介

2025年5月，辉瑞（Pfizer）以12.5亿美元预付款、最高48亿美元里程碑付款，获得三生制药旗下双特异性抗体SSGJ-707在中国以外的全球权益，潜在总交易金额超过60亿美元。这不是当周新闻，而是过去一年中国创新药出海最有代表性的定价锚点。结合2026年第一季度中国biotech出授权继续放量的趋势，本期讨论：外资用真金白银给中国创新药定的这个价，有没有进入A股和港股创新药公司的股票价格里？

## 核心看点

- **从赚服务费到赚授权费**：中国药企在全球产业链中的角色，从CRO/CMO合同服务，升级到BD出授权里程碑收入。据PharmaSource Global等行业数据，2025年全年出授权总金额约1370-1380亿美元，创历史新高；平均预付款从2022年的5200万美元涨到2026年约1.72亿美元，涨幅超过230%。
- **SSGJ-707：为什么是双特异性抗体？**：PD-1单靶点市场已经内卷，双特异性抗体把PD-1免疫激活与VEGF血管抑制组合在同一分子里，辉瑞选择中国公司的管线，不是因为便宜，而是因为三生制药有先发临床数据。
- **减重药出海也起来了**：阿斯利康与石药集团减重药授权协议，据阿斯利康官方公告，石药集团将获得12亿美元预付款及最高35亿美元开发和监管里程碑付款，另有销售分级特许权使用费；部分行业媒体将协议潜在总额估算到185亿美元级别，超过辉瑞/三生那笔。出海授权的热点从肿瘤延伸到代谢疾病。
- **不是所有人都能拿到这张票**：有真正差异化靶点、有中国已积累的临床数据、有能力谈判的团队、有足够多的候选分子——这四个条件同时满足的公司是少数。
- **有没有进股价？**：三生制药港股在交易公告后一度大涨三成以上。但这个溢价能否扩散到整个板块、估值中枢能否整体上移，是市场下一阶段争论的核心。港股通创新药指数估值分位仍在历史偏低区间。
- **ASCO数据窗口**：美国临床肿瘤学年会2026年5月29日至6月2日在芝加哥举行，是中国创新药年度数据发布的重要节点。双抗或ADC数据超预期，可能进一步触发外资大药企授权意愿。
- **反转条件**：FDA临床审批高风险漏斗（SSGJ-707后续美国临床不确定性）；地缘政治对中国CRO/BD交易的潜在限制；出海逻辑内部分化——差异化管线赢，同质化公司两头不沾。

## 涉及机构与公司

辉瑞（Pfizer）、三生制药（1530.HK）、百济神州、信达生物、荣昌生物、康方生物、恒瑞医药、药明康德、康龙化成、阿斯利康、石药集团（CSPC制药）

本期关于辉瑞/三生制药交易的内容来自公开行业媒体（FierceBiotech等）转述，非原始协议全文。关于阿斯利康/石药集团协议的官方口径引自阿斯利康公开公告，185亿美元为行业媒体对潜在总额的估算。创新药临床存在高失败风险，FDA审批不确定性高，市场反应不可预测。
