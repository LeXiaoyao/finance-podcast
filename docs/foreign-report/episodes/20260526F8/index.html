外资重磅第8期｜Pfizer 为什么愿意付 12.5 亿美元买中国药？

发布时间：2026-05-24 12:21:25 +0800

节目简介

2025年5月，辉瑞（Pfizer）以12.5亿美元预付款、最高48亿美元里程碑付款，获得三生制药旗下双特异性抗体SSGJ-707在中国以外的全球权益，潜在总交易金额超过60亿美元。结合2026年第一季度中国biotech出授权继续放量的趋势，本期讨论：外资用真金白银给中国创新药定的这个价，有没有进入A股和港股创新药公司的股票价格里？

中国药企在全球产业链中的角色，从CRO/CMO合同服务，升级到BD出授权里程碑收入。2025年全年出授权总金额约1370-1380亿美元，创历史新高；平均预付款涨幅超过230%。行业分析师的判断是，"中国biotech不再是讨价还价的地方"。

本期还讨论ASCO年会数据窗口（2026年5月29日至6月2日）、减重药和ADC出海新热点，以及反转条件：FDA高失败率、地缘政治不确定性、管线同质化公司的分化风险。

本期关于辉瑞/三生制药交易内容来自公开行业媒体转述，非原始协议全文。
