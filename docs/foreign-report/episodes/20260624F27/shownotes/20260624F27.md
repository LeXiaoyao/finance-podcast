# 外资重磅第27期｜AI 太耗电了：外资为什么重算中国电力和算力基建

发布时间：2026-06-24 12:00:00 +0800

## 节目简介

你随手问 AI 一个问题，屏幕上只跳出一段文字，背后却是一排排 GPU 在高速运转、机柜在发热、变压器在持续供电。AI 看起来像跑在“云”上，其实跑在电、机房、冷却水和电网上。本期把视角从芯片、模型、机器人再往底层挪一层——讲电。主问题是：AI 时代，电力到底只是算力公司的成本项，还是会变成外资重新定价中国资产的一条基础设施主线？

IEA《能源与人工智能》报告给出一个量级：全球数据中心用电可能从 2024 年约 415 太瓦时，增长到 2030 年约 945 太瓦时；中国同期或新增约 1750 亿度电，增幅约 170%。高盛、摩根士丹利“自己带电来”、摩根大通资产管理的判断合在一起，意思不是“AI 火了所以电力股全涨”，而是 AI 正把电力系统、数据中心和算力基础设施，放进同一张资产定价表。本期用五张账来拆：用电需求账、电源结构账、电网设备账、数据中心效率账、财报验证账。

资产地图（不是买入清单）分四层观察：稳定基荷与低碳电源（水电、核电、火电灵活性、绿电、储能）、电网设备与变压器、数据中心液冷与效率（PUE）、以及数据中心运营商。落点始终是四道门——收入、订单、毛利率、现金流：AI 用电有没有真的写进财报，而不只是写进概念和发布会。本期最重要的一句话是：AI 的尽头不是只有芯片和模型，还有电表、变压器、冷却水和现金流。本期涉及的所有公司仅作代表性资产地图，不构成任何推荐。
