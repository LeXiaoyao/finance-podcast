外资重磅第78期｜特斯拉赴宁波审厂：造车的老本事，能吃到多少机器人新生意？

发布时间：2026-10-02 18:17:19 +0800

节目简介

坐进汽车按一下座椅按钮，身体就能平稳地往前挪——藏在座椅下面、把旋转变成前后移动的那套本事，正在被带去研究机器人的关节。九月十七日，产业链人士透露特斯拉机器人团队抵达宁波开启新一轮量产审厂，当天均胜电子涨停、拓普集团上涨百分之四点三六。市场的推理很顺：过去帮特斯拉造车，现在帮特斯拉造机器人。但拓普今年上半年全部营业收入接近一百四十二亿元，机器人执行器收入约一千四百零五万元——每一千元收入里只有大约一元来自机器人。消息本身也要看成色：次日回访，拓普称未接到本轮审厂通知，均胜以客户保密为由未回应，特斯拉没有确认；能确认的是特斯拉二季度材料里写的，弗里蒙特正在安装第一代机器人生产线，最初生产的机器人用于采集训练数据和开发功能。通过审厂是拿到考试资格，采购量还要另外谈。

技术怎么迁移：拓普从汽车线控制动的电机、减速机构、电控和软件延伸到机器人执行器，直线执行器、旋转执行器和灵巧手电机已进入小批量交付；双林股份从二零零零年开始做座椅水平驱动器，把精密传动工艺带到行星滚柱丝杠，宁海梅桥工厂一期十万套产线具备量产能力，面向国内头部新势力车企的关节模组处于小批量生产；均胜电子的机器人控制器已向头部机器人客户量产供货。市场有多大：机构估计今年上半年全球人形机器人出货约一万九千一百台、全年接近六万台、行业收入约十六亿美元；摩根士丹利六月下旬把中国人形机器人今年出货预测从两万八千台上调到五万台，预计二零三零年四十四点六万台、市场约一百五十亿美元。大摩去年初拆解的物料清单显示，一台机器人零部件成本约四万九千五百美元，执行器约占百分之五十六、每台约两万八千美元；按此粗算，拓普上半年的执行器收入只相当于七十台左右机器人的整套用量。假设五万台、两成份额，对应约二十亿元人民币，也只占拓普全年收入的百分之七左右。高盛资产管理六月底的走访观察则认为，人形机器人广泛商业可行仍需数年。

三家公司的现实：拓普执行器收入同比增八成多，毛利率约百分之二十七、同比降约三点五个百分点，集团净利润约十点二三亿元、同比降约两成一，经营活动净现金流约二十六亿元；均胜上半年收入约二百八十一亿元，汽车安全系统约一百八十亿元仍是最大板块，机器人收入未单列；双林净利润约九千一百万元、同比降约六成八，半年报写明机器人等新业务收入占比还很小。宁波有可能形成新的机器人产业链，部分环节已经开始形成，最先具备商业可行性的是有明确产品、能完成验证和交付的精密机电部件。压力来自降本：特斯拉给机器人定的长期目标价是两万到三万美元，而大摩拆出的零部件成本接近五万美元，差距很大一部分要靠供应链来填。往后最直接的验证数字，是拓普财报里单列的机器人执行器收入：从千万级走到亿级而毛利率守得住两成以上，说明小批量变成了重复采购；收入上去、毛利率一路下滑，则是订单拿到了、利润让给了客户。审厂让机会走进工厂，持续交付才能让机会留在财报里。本节目仅作公开资料解读和行业观察，不构成任何投资建议或个股推荐。
