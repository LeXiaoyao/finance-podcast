外资重磅第75期｜美联储三年来首次加息：科技股的高估值，还撑得住吗？

发布时间：2026-09-21 12:03:40 +0800

节目简介

美联储重新加息了。按最熟悉的市场剧本，利率上去，科技股的高估值就该承压。可加息之后，汇丰仍然看好美国股票，给出的理由恰恰是人工智能投资和企业盈利。央行踩刹车，机构却还在看增长，这两种判断为什么会同时出现？北京时间九月十七日凌晨，美联储把政策利率目标区间上调零点二五个百分点，来到百分之三点七五至百分之四，十二位委员全票通过，这是二零二三年七月以来的首次加息。这一步还有一层背景：现任主席凯文·沃什今年才上任，六月他主持第一次议息会议时选择按兵不动，但会后明确说过——必须承认通胀依然很有黏性，尤其是能源价格带动的那一部分，如果数据表明通胀回不到百分之二的目标，会毫不犹豫动用一切必要工具，包括在必要时重新加息。三个月后，他把这句话兑现了。官方声明给出的理由里，除了国内支出有韧性、通胀仍然偏高，还点了一个外部因素：地缘政治冲突推高了全球能源价格。科技投资在这里扮演着特别的角色——它既是企业收入和利润增长的来源，也在增加当下对设备、能源和资金的需求。同一场技术浪潮，一边给科技股提供增长理由，一边可能抬高支撑这些增长所需的资金成本。

先看一个容易让人判断反了的数字：美国二季度实际经济增长按年率折算是百分之一点五，比一季度放慢。只看这个总数，很容易觉得经济既然减速，为什么还要加息？但同期公布的另一个指标——把私人消费和私人固定投资加起来、剔除价格变化后，年率增长百分之四点二。前者衡量美国境内生产增加了多少，后者更接近家庭和企业自身的需求力度；差距与进口增加、政府支出下降有关：美国企业买进海外生产的设备，投资需求很旺，但这些设备对应的生产发生在国外。就业也没塌：八月新增非农十六万两千人，失业率百分之四点一。物价方面，八月消费者价格同比涨百分之三点四，当月汽油涨价贡献了超过三分之一的整体月度涨幅；剔除食品能源的核心价格同比从七月的百分之二点五降到二点四，但核心环比仍涨百分之零点三。能源涨价来自地缘冲突和供给，利率工具够不着这一端——再高的利率也变不出一桶油；它真正作用的地方在需求侧，借钱变贵，价格就更难一轮一轮往上传。换句话说，央行治不了涨价的源头，只能压住它扩散的通道，而这条通道上站着的恰恰是那些本来就在放慢的行业。这种分化在人工智能投资上尤其明显：一座数据中心要先买芯片、建机房、接电网，随后才能把算力卖出去——建设需求先发生，生产率收益后兑现。美联储理事丽莎·库克今年二月讨论过这个问题：为了未来的生产率收益，企业已经在数据中心和芯片上大举投资，这些投资增强当下需求，可能让经济能够承受的均衡利率比疫情前更高。但明尼阿波利斯联储的公开分析也提到，人工智能建设旺盛的同时，住宅等对利率敏感的投资受到抑制，抵消了一部分扩张。对科技股而言矛盾就出现了：投资热潮能支撑产业链收入，却可能延长较高利率维持的时间——增长的发动机，与估值承受的压力，可能来自同一个地方。

市场因此开始重估整条利率路径。九月这份预测里最直接的一条是：十八位官员预计到今年年底政策利率会升到百分之四至百分之四点二五，也就是美联储自己的预测就已经含着“年内还有一次加息”；更往后看，二零二七年末政策利率中位数从六月的百分之三点六上调到百分之四点一。汇丰九月十七日预计十二月还会加息一次、随后二零二七年保持稳定；瑞银同日维持十二月再加一次的判断，但认为市场对后续紧缩的定价偏高。海外事件预测市场上，九月十八日十二月会议加息零点二五个百分点的隐含概率约百分之六十六、维持不变约百分之三十二——这是交易价格反映的押注，不是投行预测，但方向与两家机构和美联储自己的年底预测都对得上。这些分歧会进入股票价格：买一家公司的股票买的是它未来持续创造现金的能力，利率越高、等待的成本越高，同样一笔未来现金折算到今天就越小，现金越集中在遥远的未来越敏感。瑞银对九月十六日交易的回顾显示，十年期国债收益率来到百分之五、当天只小幅上升，三十年期反而略有下降——短期政策收紧，长期利率还要同时消化增长、通胀和债券供给。七月的会议纪要已经指出股票估值仍然较高、由人工智能热情和强劲利润支撑；一旦盈利兑现放慢，投资者可能同时调低利润预测并要求更高回报，公司会承受两次调整。用一组假设说清盈利与估值的关系：每股盈利一元、市场给三十倍市盈率，股价三十元；后来盈利增长两成到一元两角，但估值倍数降到二十四倍，股价变成二十八元八角——公司多赚两成，股价反而跌了百分之四。这两股力量的拉扯，加息之后两个交易日就演了一遍：九月十七日决议当天美股尾盘跳水、三大指数收跌；九月十八日纳斯达克涨百分之一点七、标普五百涨百分之一点一、道琼斯涨百分之零点六，七巨头全线上涨，英伟达涨百分之二点五五、特斯拉二点二七、亚马逊二点一二、微软一点五二、苹果一点三八，同时长期国债收益率和油价回落。同一件事两天两个方向：第一天定价的是更贵的资金，第二天定价的是仍在增长的盈利。传到中国市场也会分化：在香港上市、需要与全球资产争夺资金的科技公司，美元资产回报要求提高会影响国际投资者愿意接受的估值；对内地科技产业链，海外数据中心继续建设可以支撑设备和零部件需求，但融资成本长期偏高又会提高客户对新项目回报的要求。这次加息更像是在提高增长的验收标准：市场愿意继续相信技术进步，但为未来付出的价格会更在意利润出现的时间，以及获得这些利润需要先投入多少钱。本节目仅作公开资料解读和市场观察，不构成投资建议。
