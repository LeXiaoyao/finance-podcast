外资重磅第12期｜韩国股市疯牛还是产业周期？——KOSPI、SK海力士与长期结构隐患

发布时间：2026-05-28 10:23:31 +0800

节目简介

韩国有全球最低的生育率，有高企的家庭债务，有长期承压的房地产，也有跟中国很相似的出口导向型产业结构。但就在这些长期压力都没有消失的情况下，韩国股市这两年却跑出了全球主要市场里最夸张的一轮行情。本期核心问题不是"要不要买韩国股票"，而是：当一个国家的宏观压力还在，但某条产业周期突然爆发，股市到底应该看宏观，还是看产业？

据Reuters报道，KOSPI 2025年上涨约76%，创1999年以来最大年度涨幅；2026年5月27日盘中最高约8450点，年内涨幅接近翻倍。SK海力士从不到1000亿美元攀升至突破1万亿美元市值，不到16个月接近十倍级别重估。外资重新定价韩国，三条逻辑同时在跑：AI和HBM带来的盈利持续上修（高盛2026年连续第三次上调韩国盈利预测）、Corporate Value-up企业价值提升改革、全球资金寻找美股AI资产的亚洲替代品。

HBM是这轮行情最核心的底层逻辑。GPU是发动机，HBM是高速油管——SK海力士在HBM3E这代产品上率先完成量产，成为英伟达最核心的HBM供应商之一。用A股做镜子：韩国现在更接近有产业逻辑支撑的2006–07，而非杠杆驱动的2015，但已经不是便宜阶段。接下来要看三个信号：HBM价格和订单有没有松动、利润增长能不能追上估值扩张、资金有没有外溢到没有业绩支撑的小票。

长期来看，韩国生育率2023年约0.72，是全球有完整统计记录的经济体里最低的一档；家庭债务相当于居民可支配收入的170%以上；房地产有日本1990年后的参照压力。核心结论：短期看HBM，中期看Value-up改革，长期看人口和家庭资产负债表。这对中国投资者最有价值的启发，是理解一个市场的定价顺序——产业周期足够强时，股市会先给产业链定价；但当估值把产业逻辑打满之后，宏观约束迟早会重新回来。
