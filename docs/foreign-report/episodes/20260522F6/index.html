花旗警告资源再定价：能源危机、厄尔尼诺与中国资源股

发布时间：2026-05-22 12:00:00 +0800

节目简介

据公开财经媒体转述，花旗近期对全球农产品价格发出警示：未来六到十二个月，价格风险可能"严重偏向上行"。本期从霍尔木兹海峡、OPEC+供给、厄尔尼诺天气三条线切入，拆解全球资源供给端为何正在经历系统性收紧。

这条主线对中国市场的影响，主要体现在两个方向：一是输入性通胀可能影响下半年货币政策腾挪空间；二是资源股、能源股、有色金属、化肥农药等方向，可能因为全球定价资源品价格上行而出现新的盈利验证逻辑。

需要说明的是，本期关于花旗观点的内容来自公开财经媒体转述，并非原始研报全文。资源品价格波动极大，供给冲击可能在短时间内逆转。
