# 外资重磅第7期｜霍尔木兹重启：外资定价锚从资源股切到成本修复？

## 本期简介

美国总统特朗普5月23日宣布美伊协议"基本完成谈判"，内容包括开放霍尔木兹海峡。英国金融时报同步确认，美伊接近同意将停火延长六十天，逐步重新开放海峡。本期讨论的核心问题：油价风险溢价退潮之后，外资会不会把中国资产的定价锚，从"资源股受益"切换到"成本端修复"？

## 核心看点

- **美伊协议接近达成**：霍尔木兹通航风险预期改善，布伦特原油中的地缘溢价面临消退，外资重新评估油价、通胀和板块利润再分配三张表。
- **成本端修复的逻辑**：航空、化工中下游、火电的燃料成本压力有望阶段性缓解。航油成本传导、化工品价差、长协煤/现货煤分化是关键传导环节。
- **资源股的重新定价**：油气上游前期计入的霍尔木兹溢价需要重新评估。铜、黄金、煤炭各自逻辑不同，不能笼统说"资源股承压"。
- **航运的两头拉扯**：运费短期承压 vs 贸易量中期改善。
- **后续信号**：布伦特原油能否在某个区间站稳、A/H股板块是否开始重新排序、OPEC+六月七日产量会议。

## 说明

美伊协议尚未最终签署，特朗普仍保留重启军事行动的选项。本期关于地缘事件的信息均来自新华社、央视和英国金融时报等权威公开报道。
