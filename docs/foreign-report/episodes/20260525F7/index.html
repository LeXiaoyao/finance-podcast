外资重磅第7期｜霍尔木兹重启：外资定价锚从资源股切到成本修复？

发布时间：2026-05-24 11:54:57 +0800

节目简介

美国总统特朗普5月23日宣布美伊协议"基本完成谈判"，内容包括开放霍尔木兹海峡。英国金融时报同步确认，美伊接近同意将停火延长六十天，逐步重新开放海峡。本期核心问题：油价风险溢价退潮之后，外资会不会把中国资产的定价锚，从资源股受益切换到成本端修复？

外资通常会把这类地缘事件拆成三张表：油价风险溢价、通胀传导、板块利润再分配。当霍尔木兹从通航受阻转向逐步恢复，上游油气中前期计入的地缘溢价需要重新评估；航空、化工中下游和火电的燃料成本压力则有望阶段性缓解。市场接下来要分辨的，是谁赚了地缘溢价的钱、谁赚了成本修复的钱。

美伊协议尚未最终签署，特朗普仍保留重启军事行动的选项。本期关于地缘事件的信息均来自新华社、央视和英国金融时报等权威公开报道。
