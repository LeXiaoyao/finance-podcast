外资重磅第16期｜地产没反转，外资买幸存者：房价拐点、现金流重估与下一轮蓄水池

发布时间：2026-06-02 08:36:56 +0800

节目简介

中国地产并没有全面反转：2026 年前四个月，新建商品房销售面积约 2.53 亿平方米、同比下降 10.2%，销售额约 2.3 万亿元、下降 14.6%，房地产开发投资下降 13.7%，新开工面积下降 22.0%。但与此同时，价格端出现局部止跌信号——4 月一线城市新房价格环比上涨 0.1%、二手房环比上涨 0.4%。本期讨论一个反直觉的现象：行业还没反转，为什么外资开始重新翻中国开发商、物业公司和房产服务平台的财报？

本期把这条线拆成八段：一是三个拐点为什么不会同时到来——销售量、核心城市房价、少数房企现金流是三条独立的曲线；二是 2026 年前四个月的硬数据 + 一线二手房环比转正背后的"局部止跌、整体出清"；三是外资为什么从"整体打折"切到"挑幸存者"——中海、华润、龙湖代表的财务稳健派如何在新规则里被重估；四是物业（中海物业、保利物业、华润万象生活）的估值锚切换 + 贝壳一季度 GTV 同比下降 15.6%、净利润同比增长 46.7% 背后的存量房平台逻辑；五是 2027 到 2031 年这一波被反复讨论的改善型需求——为什么核心城市好房子可能仍有结构性机会；六是真正拐点的四条线（销售跌幅、二手房价格、库存、企业现金流）+ 三类买房人（刚需 / 改善 / 投资）的判断框架；七是居民财富蓄水池的迁移——从房地产单一池子分散到核心房产、高股息、黄金、保险养老和权益龙头；八是房企四阶段历史（1998 商品化、2009-2016 高杠杆扩张、2016-2021 房住不炒、2021 至今信用出清）解释为什么"幸存者"才是这一轮的关键词。

外资现在买的不是地产复苏的浪漫想象，而是出清之后的确定性折价。中国地产不会回到过去那个普涨时代，但它也不会简单归零——下一轮机会会更窄、更挑剔、更看现金流，也更看城市分化。对股票来说是挑幸存者，对买房来说是挑核心资产，对居民财富来说是寻找新的蓄水池。
