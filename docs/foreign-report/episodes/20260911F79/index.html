外资重磅第79期｜工业利润增长15.7%，去掉电子只剩6.5%：这轮增长，谁在赚钱？

发布时间：2026-10-02 19:54:08 +0800

节目简介

同样是工厂，做电子设备的，今年前八个月利润比去年翻了一倍多；做汽车的，利润却少了百分之十六。把它们和其他行业加在一起，中国规模以上工业企业利润约五点二七万亿元，同比增长百分之十五点七。一个挺亮眼的总数，里面装着完全不同的生意。单看八月，利润只增长百分之四点二，是今年最慢的一个月；前八个月营业收入只增长百分之六点六，每百元收入的成本比去年少了四角一分、利润多了四角四分，乘上九十三万亿元的收入规模，就是七千多亿元的新增利润。这七千多亿元是谁挣到的？统计局的官方解读给了答案：电子行业对利润增长的贡献率达到百分之六十二，而它在利润总额里只占百分之十六左右。按公布数据粗略推算，把电子行业拿出去，其余工业行业的利润增长大约是百分之六点五。

利润往电子集中，外资的钱也在往同一个方向走。私募排排网整理的数据显示，截至九月十一日的一个月里，高盛调研一百零一家内地上市公司，电力设备十四家、电子和机械设备各十三家；摩根士丹利一百家里电子十九家；摩根大通六十七家里电子二十家；瑞银七十一家里电子十七家；花旗七十二家里电子十五家。高盛持股市值超过两亿元的五十七家公司里电子占二十五家，其中五十二家是二季度新进。但按企业类型看，前八个月股份制企业利润增长百分之二十点四、国有控股百分之十点三、私营百分之十点四，外商及港澳台投资企业只增长百分之二点三——外资投行在买中国的电子公司，外资工厂的利润却几乎没涨。原材料是另一种赚法：采矿业利润增长百分之三十五点一，有色冶炼百分之八十二点九，化工百分之五十一，靠的是涨价。八月出厂价格同比上涨百分之三点八，购进价格上涨百分之五点八；购进端有色金属材料涨百分之十九点八、燃料动力涨百分之九点八，出厂端生活资料反而下降百分之零点五——涨价从上游出发，走到消费品门口停住了。汽车制造业收入增长百分之二点九、成本增长百分之四、利润下降百分之十六；电力热力供应行业利润下降百分之十二。

钱有没有收回来？八月末应收账款二十九点四八万亿元、同比增长百分之九，快于收入；平均回收期七十二点二天，比去年多零点九天；产成品存货七点三六万亿元、同比增长百分之十一。九月制造业采购经理指数回到五十点一，生产指数五十一点七为今年最高，新订单五十点五略低于上月；主要原材料购进价格指数六十点八、出厂价格指数五十四，购进比出厂高出将近七个点，挤压比八月更重；大型企业五十点六，中型四十九点七、小型四十八点九仍在收缩区间。落到资产上：电子链条利润翻倍已是公开信息、外资二季度已集中买进，往后看订单延续和新产能投放后的利润率；上游资源利润跟着商品价格走，持续性取决于国际油价和金属价格；中下游的汽车、家电和一般消费品成本在涨、售价涨不动，转机要等出厂价格涨幅追上购进价格。十月下旬公布前九个月数据时，最值得看的是电子行业那个百分之六十二的贡献率：总增速稳住而贡献率下降，是增长在扩散；总增速回落而贡献率上升，是更依赖这一个行业。十五点七是所有工厂加在一起的数字，去掉电子，它是六点五。本节目仅作公开数据解读和宏观观察，不构成任何投资建议或个股推荐。
