外资重磅第76期｜单车日入338元已打平，小马季度仍亏6574万美元：无人出租车的钱花在哪？

发布时间：2026-09-27 02:34:12 +0800

节目简介

一辆出租车，最显眼的那个人不见了。没有司机，也不用给司机发工资，车费是不是应该更便宜，开车的公司是不是应该更赚钱？二零二六年九月，这个问题已经不能只看演示视频了：九月三日，特斯拉在美国奥斯汀推出专门用于无人出租车的赛博出租车，四十多辆没有方向盘和踏板的双座车在限定区域提供服务，九月二十二日到二十七日同款车又来到香港作静态展示。另一边，小马智行已经在中国部分城市交出了单车运营收支打平、进而转正的成绩——截至二月底的一个月，深圳第七代车单车日均净收入三百三十八元、每天二十三单，单车经济模型盈亏平衡；但八月发布的二季度财报里，公司整体仍有约六千五百七十四万美元的经营亏损。车已经开始养活自己，为什么公司还养不活自己？高盛去年五月就预计中国无人出租车会先在一线城市、于二零二六年开始盈利，现在看是发生了——但高盛说的和小马做到的，都是城市运营这一层，不是整家公司。无人驾驶，不等于无人干活：清洁、维修、充电、远程协助、地面运营都还在，这门生意真正要证明的，是车越多、单越多时，背后的支持系统能不能长得更慢。

小马二季度把这段距离摊开了：截至六月底全球车队一千九百七十五辆，年底目标从三千辆上调到三千五百辆以上；当季总收入约三千六百二十二万美元，其中无人出租车约一千二百零七万美元、比上年同期约一百五十三万美元增长将近七倍，已占三分之一；全部业务毛利约六百三十五万美元，而研发费用约五千六百二十四万美元——光这一项就远超全部毛利，这才是单车收支改善、公司仍大幅亏损的核心原因。也有对公司有利的变化：总收入比去年同期增加约一千四百七十七万美元，经营亏损只扩大约四百四十七万美元，业务在长大、亏损没有同速膨胀，但绝对金额还没开始下降；二季度经营活动净流出约四千四百万美元，覆盖折旧不等于有现金再买下一批车。文远知行是另一种组合：上半年自动驾驶车辆及相关业务约占一半收入，另一半来自面向车企的辅助驾驶方案和数据服务；二季度毛利约八千六百九十万元人民币，研发约四点三四亿元，毛利率改善主要来自辅助驾驶方案和海外业务；国内单车日均订单超过二十一单、比一季度提高约两成四。特斯拉的设想是从制造那一刻就做成高频载客的专用工具：高盛九月初测算，如果规模化后车辆成本做到两万至三万美元，对比五万至十万美元的竞争方案，每英里可能有五到三十美分的成本优势——但这是条件式估算，而且高盛自己也说，软件能否支撑更大范围稳定运营，可能比车便宜多少更重要。一组假设说明：每天两百元固定费用，二十单每单分摊十元，十单就是二十元。特斯拉二季度收入约二百八十二亿美元，来自汽车、储能、服务等，无人出租车没有单独拆出，拿集团利润对比小马文远的亏损，是把资金来源误当成新业务已经赚钱。

跨城市复制决定能走多快。九月九日小马介绍多哈进展：乘客能通过合作伙伴应用付费叫车，但商业试点车内配有受训安全人员；九月十日小马在克罗地亚萨格勒布启动二十二公里、连接市区和机场的全无人载客测试；同一天文远知行、优步和当地车队运营方拿到西班牙许可，初期二十辆车在车内人员监督下做准备，商业服务目标年底。特斯拉也要过这一关：九月四日美国国家公路交通安全管理局对赛博出租车是否符合联邦安全标准启动问询，九月十日升级为正式特别调查令、列出二十一项要求，答复期限九月三十日——生产线能造多少车，和允许多少车以什么条件持续上路，是两件要同时推进的事。各家都在找合作伙伴：文远出技术、优步出平台、当地运营方管车队；特斯拉也在官网征集购买车队和提供场站的合作意向。但轻资产省的是自己先掏的钱，不是整个系统不用花的钱。摩根士丹利七月预计未来三年运营成本还有下降空间、到二零二八年典型车辆每次出行约有一成利润，但这是车辆运营判断，不是集团利润保证；而且成本省下来以后，一部分会通过更低车费给乘客，一部分被平台和车队伙伴分走，剩下的才轮到股东。看相关资产时，小马和文远更直接暴露在商业化进度里但收入结构不同；特斯拉的估值还要容纳汽车、储能等业务；上游芯片、传感器、线控部件和运维服务拿到订单可能早于车队盈利，但也会被要求降价，特斯拉的视觉路线也不意味着每家激光雷达厂商都受益。无人出租车已经出现局部可持续运营的证据，接下来竞争的是把这种能力复制到更多车和城市、同时控制新增投入；最近一个可验证节点是九月三十日特斯拉对特别调查令的答复。方向盘可以一次拿掉，支撑一趟出行的成本要一项一项降下来——真正跑通的那一天，是这趟车费养得起车，也养得起背后的公司。本节目仅作公开资料解读和行业观察，不构成任何投资建议或个股推荐。
