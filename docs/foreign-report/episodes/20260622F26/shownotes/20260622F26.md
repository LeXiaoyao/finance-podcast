# 外资重磅第26期｜人形机器人：外资不看它会不会走路，看它会不会回本

发布时间：2026-06-22 12:00:00 +0800

## 节目简介

人形机器人，很多人第一反应是家里的"全科保姆"——早上做咖啡、中午洗衣服、晚上做饭。但第一波商业化的主战场，大概率不在家里，而在工厂。工厂里的机器人更像"专科工人"：先学会一个岗位（搬运、分拣、巡检、上下料、质检），场景更固定、动作更重复、客户更容易算账。本期的主问题是：人形机器人现在到底处在什么位置——是下一条真实产业周期，还是又一次估值先行的主题交易？

先给三组数字：高盛口径下 2035 年潜在市场约 380 亿美元，IFR 数据里中国已是全球最大的工业机器人应用市场，摩根士丹利远期看到 2050 年市场或超 5 万亿美元。三组数字合在一起说明：人形机器人已经从远期科幻，进入"可建模产业"，但还没进入全面财报兑现阶段。所以核心判断是——视频不是生意。Demo 像样板房，订单才是入住率；视频是预告片，财报才是正片。从视频走到财报，中间隔着试点、订单、复购、成本曲线四道门。

本期把资产地图（不是买入清单）拆开看：海外这条线更像"整机叙事＋大脑＋资本故事"（特斯拉 Optimus、Figure、波士顿动力）；中国这条线，整机有宇树、优必选这种已经能放进财报的样本，更大的筹码在供应链——零部件、成本和量产交付（拓普集团、三花智控、绿的谐波等核心环节，多数仍只能算增量预期）。最后落到三个误判和三个信号，对应一个更简单的判断：机器人有没有从"项目"变成"产品"。本期最重要的一句话是：真正的转折点，不是它第一次像人一样走路，而是它第一次像设备一样回本。本期涉及的所有公司仅作代表性资产地图，不构成任何推荐。
