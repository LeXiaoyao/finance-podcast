# 外资重磅 · 事实口径与数据表达守护规则

本文档用于约束「外资重磅」每期选题、出稿、发布前校验中的事实表达。目标是保留财经播客的表达张力，同时避免把盘中行情写成收盘结论、把旧机构观点写成最新动作、把分化数据写成全面向好。

## 一、指数和行情数据口径

### 1. 所有行情数据必须带时间口径

- **规则**：所有指数涨跌幅、点位、区间表现，必须说明统计时点。
  **示例**：“截至5月19日下午盘中”“以5月19日收盘数据计算”“截至本周五收盘”“过去一周，按周五收盘价计算”。

### 2. 不要把盘中数据写成最终结论

- **错误写法**：“恒生指数本周下跌2.1%。”
  **更稳写法**：“截至5月19日下午盘中，恒生指数较5月12日附近高位回落约2%左右。”

### 3. 盘中行情必须使用弱确定性词

- **盘中数据**：必须使用“约”“大约”“附近”“盘中”等弱确定性词。
  **收盘数据**：可以使用更确定表达，但仍需说明收盘日期和计算区间。

### 4. 指数点位和涨跌幅不要过度精确

- **口播优先表达**：“约两个百分点”“接近四个百分点”“五千点附近”。
  **避免表达**：小数点后一位的精确涨跌幅，除非数据已经核实且需要保留。

## 二、宏观数据口径

### 1. 宏观数据必须说明月份和发布主体

- **规则**：写明数据月份和发布主体。
  **示例**：“国家统计局公布的4月数据”“海关总署公布的4月外贸数据”“央行公布的4月金融数据”。

### 2. 避免过满表达

- **慎用表达**：“全面超预期”“全面改善”“确认复苏”。
  **优先表达**：“数据组合偏积极”“部分指标好于预期”“外需有韧性，但内需仍需验证”“复苏方向出现，但持续性还需要观察”。

### 3. 数据分化必须写成分化

- **规则**：如果出口、进口强，但消费、投资、信用弱，要写成“数据分化”，不能写成“全面向好”。
  **目标**：让听众理解经济结构，而不是被单个亮点误导。

## 三、外资机构观点口径

### 1. 不要把旧报告或此前观点写成刚刚发生

- **无法确认发布时间时使用**：“此前公开报道显示”“近期被市场重新关注的策略观点”“公开转述中提到”“从今年以来的外资框架看”。

### 2. 不要冒充拿到原始研报

- **禁止表达**：“我们拿到某某投行研报”，除非确实有原始报告。
  **推荐表达**：“公开报道转述”“财经媒体援引”“市场公开摘要显示”“根据公开资料整理”。

### 3. 外资评级和目标价必须区分清楚

- **必须核对**：是否为单只股票。
  **必须核对**：是否为指数。
  **必须核对**：是否为12个月目标。
  **必须核对**：是否为潜在上行空间。
  **必须核对**：是否为情景假设。
  **底线**：不能把单只股票目标价、指数目标、评级变化和潜在上行空间混写。

### 4. 机构观点存在时间差时必须说明

- **推荐表达**：“这个观点不是今天才出现，但在最近的市场环境下，它重新变得重要。”
  **目的**：避免把旧观点包装成当天新动作。

## 四、节目表达规则

### 1. 每期必须有一个核心问题

- **规则**：不要只是新闻堆砌。
  **示例**：“外资为什么重新看多？”“便宜之后，盈利能不能接上？”“AI叙事到底兑现到哪一层？”“港股科技涨的是估值，还是利润？”

### 2. 每期最好有一个可记忆结构

- **可用结构**：“三张牌”“两道门”“三个验证点”“一条资金链”“四个观察信号”。
  **目标**：帮助听众在节目结束后记住主线。

### 3. 标题和开头可以有冲击力，但正文必须收回来

- **规则**：可以吸引人，但不能制造确定性错觉。
  **做法**：标题提出矛盾，正文补充时间口径、来源口径和风险条件。

### 4. 结尾必须保留免责声明

- **固定句**：“本节目仅作宏观观察和研报解读，不构成任何投资建议。”

## 五、发布前事实检查清单

每次发布前，Codex 必须检查：

- [ ] 所有指数涨跌幅是否有“截至某时点”口径
- [ ] 所有盘中数据是否使用“约、大约、附近、盘中”等表达
- [ ] 宏观数据是否写明月份和发布主体
- [ ] 是否存在“全面超预期”“确认复苏”等过满表述
- [ ] 外资观点是否区分“原始报告”和“公开媒体转述”
- [ ] 是否把旧观点误写成新观点
- [ ] 是否存在未经核实的目标价、涨跌幅、资金流数字
- [ ] 是否保留投资风险免责声明
